# **👤 Module 1 – Charging Operations**

### **Purpose**

Help EV users locate charging stations and manage their charging activities.

---

## **👤 EV Driver Functions**

* User Login/Register  
* View Nearby Charging Stations (Google Maps \+ GPS)  
* Search Charging Stations  
* Filter by:  
  * AC/DC  
  * Connector Type  
  * Charging Power  
  * Operator  
* View Charging Station Details  
* Google Maps Navigation  
* Charging Cost Calculator  
* Smart Charging Recommendation (Rule-Based)

### **CRUD 1 – Charging Session**

* Create Charging Session  
* View Charging History  
* Update Charging Session  
* Delete Charging Session

### **CRUD 2 – Charging Reminder**

* Create Charging Reminder  
* View Reminder List  
* Update Reminder  
* Delete Reminder

### **Mobile Features**

* Google Maps  
* GPS  
* Local Notifications

---

## **👨‍💼 Administrator Functions**

**None**

*(Module 1 is only accessible by EV Drivers.)*

# **👤 Module 2 – Infrastructure Planning ⭐ (AI Module)**

### **Purpose**

Support EV charging infrastructure expansion through community proposals and planning analysis.

---

## **👤 EV Driver Functions**

* View Infrastructure Coverage Map  
* View Existing & Proposed Charging Stations  
* View Infrastructure Priority Recommendation  
* Submit Charging Station Proposal (CRUD)

### **CRUD – Charging Station Proposal**

* Create Proposal  
* View Proposal  
* Update Proposal  
* Delete Proposal

Proposal includes:

* GPS Location  
* Proposed Address  
* Reason  
* Expected Demand  
* Photo

### **Community Support**

* Support (Vote) Charging Station Proposals  
* View Community Support Count

---

## **👨‍💼 Administrator Functionsk**

* View Submitted Charging Station Proposals  
* Review Proposal Details  
* Perform Infrastructure Gap Analysis  
* View Infrastructure Priority Recommendation  
* View AI Infrastructure Planning Analysis (Gemini API)  
* Approve Proposal  
* Reject Proposal  
* Update Proposal Status

Proposal Status:

* Pending  
* Under Review  
* Approved  
* Rejected

### **AI Feature (Google Gemini API)**

AI Infrastructure Planning Assistant

Workflow:

* User submits proposal  
* System performs rule-based analysis  
* Gemini AI analyzes proposal  
* AI generates planning suggestions and explanations  
* Administrator reviews proposal with AI analysis  
* Administrator approves or rejects proposal
